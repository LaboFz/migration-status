# migration-status

Page de suivi public (avancement en %, par grande phase métier) d'une
opération de bascule interne. Publié automatiquement depuis un outil interne
— ce dépôt ne contient aucune information technique (pas de nom de base, de
schéma, d'hôte, de bucket ni de secret), uniquement `progress.json` et la
page qui l'affiche.
